# Asistente Virtual GEOSOM

Proyecto para automatizar la captación y calificación de prospectos de GEOSOM, agendamiento de reunión técnica y evaluación económica.

## Objetivo

Crear un flujo automatizado donde un prospecto:
1. Interactúa con el asistente virtual e ingresa detalles de su proyecto
2. Es filtrado/calificado según criterios técnicos y de negocio
3. Si califica, agenda una hora en la agenda virtual
4. Se genera una reunión técnica + evaluación económica

## Estructura

- `01_Documentacion_Tecnica/` — contenido técnico de GEOSOM
- `02_Marketing/` — contenido de marketing / grilla de contenidos
- `03_Flujo_Conversacional/` — guion del asistente, preguntas de calificación, árbol de decisión
- `04_Configuracion_Agenda/` — configuración de agenda virtual (Calendly/Google Calendar), criterios de agendamiento
- `05_Notas_Reuniones/` — notas de trabajo del equipo
